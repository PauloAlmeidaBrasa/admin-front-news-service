Admin Front News Service

This project is a React 18 front-end application built with Vite and Material UI, designed to work as part of a microservices architecture.

🚀 Tech Stack

React 18

Vite

React Router DOM

Axios

TanStack React Query

Material UI (MUI v5)

Recharts

Lucide Icons

🧩 Architecture

This application runs as an independent microservice and is intended to be orchestrated using Docker Compose, alongside other services such as APIs and databases.

📦 Scripts
# Run in development mode
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview


The app runs on port 3000 and is exposed to the network (0.0.0.0) to support Docker environments.

🐳 Docker & Microservices

Runs as a Dockerized front-end service

Integrated into a docker-compose setup

Communicates with backend services via HTTP APIs
